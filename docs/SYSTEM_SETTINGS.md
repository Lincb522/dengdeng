# 系统设置

DengDeng AI 的运行设置保存在数据库中，保存后立即作用于新请求。数据库、JWT 主密钥和进程启动参数仍由部署环境管理，不会通过网页读写。

## 站点与功能

站点名称、Logo、说明、联系方式、文档地址和公开主页内容会同步到主页、登录页和控制台。自定义菜单只接受名称与 URL，管理员填写的 SVG 不会直接执行。后台模式会关闭公开注册和 OAuth 首次注册，已有账户仍可登录。

模型广场、推广返利、渠道监控、用户错误明细和密钥多分组都不是单纯隐藏按钮：关闭后，对应的普通用户接口或后台调度也会停止。

## 邮件与账户安全

SMTP 密码、Turnstile Secret 和 OAuth Client Secret 使用 AES-256-GCM 单独加密。普通设置与秘密在同一个数据库事务内更新。开启 Turnstile 前必须同时配置站点密钥和服务端密钥。

step-up 2FA 用于设置、备份、密钥轮换、支付和分账等敏感操作，验证结果有效 15 分钟。开启前，当前管理员必须先在账户设置中绑定 TOTP。

## 第三方登录

LinuxDO、钉钉、微信、OIDC、GitHub 和 Google 共用 state、一次性登录码与可选 PKCE。OIDC 严格校验开启后，还会验证 ID Token 的签名、Issuer、Audience、过期时间和 Nonce；JWKS 地址必须来自受信任的身份提供商。

OAuth 流程状态保存在共享数据库，因此多实例部署时回调不要求落到发起登录的同一个进程。短期状态使用后立即删除，过期记录会在创建新流程时清理。

每种注册来源可以单独发放余额、并发、RPM、分组订阅和四个平台的日/周/月额度。“首次绑定时追加发放”仅对已有账户第一次绑定该来源生效，并由唯一数据库记录防止重复发放。

## 风控

风控短语按请求正文做不区分大小写的匹配。“拦截”会在请求进入调度前返回 403；“仅记录”只写入规则哈希、请求 ID、用户和密钥，不保存请求正文。建议先使用仅记录模式观察误报，再切换为拦截。

## 网关与客户端门禁

网关可分别设置未授权、限流、529 过载、其他 5xx 和网络错误的冷却时间。并发等待时间和队列深度同时限制用户、密钥与上游账号的排队规模。

Claude Code 与 Codex CLI 版本门禁默认关闭。开启后，无有效版本信号、低于最低版本、高于最高版本或命中指纹黑名单的请求会在调度前拒绝。白名单非空时，UA、Originator 或 Stainless 信号至少需要命中一项。不要在确认客户端请求头之前直接开启门禁。

OAuth 转发可以控制统一指纹、Responses metadata、Claude System 身份块、消息缓存断点和 1 小时 TTL。缓存断点重写会改变多轮请求的缓存布局，建议先在测试分组验证命中率与计费记录。

## 发布前检查

```bash
cd backend && go test ./...
cd ../frontend && pnpm build
```

发布后检查 `/health`、登录/找回密码、系统设置保存、390px 移动端、深色模式，以及至少一个实际上游请求。
