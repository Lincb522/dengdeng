# 推广现金分账

推广佣金按被推广用户的实际付费 Token 消费计提，比例为 5%–10%。佣金进入独立现金账户，不会增加、占用或抵扣 API 余额。

## 账务状态

- `pending`：结算等待期内，可用于处理退款、争议和风控。
- `available`：可申请提现。
- `locked`：提现单已创建，资金已冻结。
- `paid`：微信商家转账成功。
- 历史版本已经发到 API 余额的佣金标为 `legacy_balance`，不会再次现金打款。

提现失败或被管理员拒绝时，冻结金额原路回到现金可用额。微信接口返回不确定结果时，提现单进入 `STATUS_UNCERTAIN`，系统只使用原商户单号查询，不会换单重试。

## 微信商家转账准备

在“管理后台 → 推广分成”配置：

1. 选择已经配置并启用的微信支付 API v3 渠道。
2. 填入商户平台“商家转账”中审批通过的转账场景 ID。
3. 原样填写该场景要求的报备信息类型和真实内容。
4. 配置结算等待期、最低提现额、单笔和每日上限。
5. 确认 `SITE_PUBLIC_URL` 是可公网访问的 HTTPS 地址。

商户平台还需开通商家转账、配置接口安全 IP。收款 OpenID 必须属于该商户渠道绑定的 AppID。用户提交 OpenID 后默认为待审核，管理员验证无误才可启用；数据库只保存加密值，控制台只显示掩码。

默认启用逐笔人工审核。关闭人工审核后，已验证账户的提现会自动提交；转账处于用户确认模式时，用户需在微信内打开推广中心并点击“确认收款”。

## 对账

转账成功后，支付中心记账本会生成类别为 `referral_payout` 的现金支出。回调重复、主动查询重复和页面重复操作均使用同一提现单幂等结算。
