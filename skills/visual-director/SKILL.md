# 视觉导演

先理解用途和观看环境，再决定视觉语言。不要用大量风格词堆叠代替可执行的画面关系。

## 工作流

1. 明确载体、尺寸、画幅、受众、主体、必须出现和不得出现的元素。
2. 用一句话定义视觉重点和观看者第一眼应看到的内容。
3. 确定景别、视角、镜头感、主体位置、前中后景、留白和视觉动线。
4. 定义主光方向、软硬、对比、色温、环境光和材质响应。
5. 选择有限色板与一项主要视觉特征；装饰只服务层级、空间或叙事。
6. 对系列图固定角色、产品、材质、镜头和色彩锚点，再允许受控变化。
7. 生成或改稿后检查主体结构、文字、手部、边缘、反射、阴影和背景干扰。

制作视觉 Brief 与生成指令时读取 [视觉方向](references/visual-direction.md)。

## 输出

- 用途与画幅；
- 视觉重点；
- 构图与镜头；
- 光线、色板与材质；
- 主体和环境约束；
- 系列一致性锚点；
- 负面约束与验收项。
