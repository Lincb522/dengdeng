# 来源评估

## 来源优先级

针对不同主张选择拥有事实的来源：

- 产品行为、模型和价格：官方文档、版本记录、状态页；
- 软件 API：固定版本的官方文档、源码和测试；
- 法律与政策：政府、监管机构和正式文本；
- 学术结论：原始论文、数据和方法；
- 公司事件：公司公告与监管披露，再用独立报道补充；
- 用户体验：可追溯的真实使用报告，不能替代产品契约。

## 记录字段

```text
来源：
发布日期/更新时间：
访问日期：
版本或地区：
支持的主张：
证据类型：直接 / 间接
限制：
```

## 冲突处理

按以下顺序检查：

1. 是否描述不同版本、地区、套餐或时间；
2. 是否使用不同定义、分母或统计窗口；
3. 一方是否只是转述另一方；
4. 是否存在已发布的更正或弃用说明；
5. 哪个来源更接近拥有该事实的系统。

无法消除冲突时保留双方，并说明为何更倾向其中一项或为何不能判断。

## 引用要求

- 引用放在它支持的句子或段落旁；
- 一个引用不承担页面未明确支持的更强结论；
- 不引用搜索结果页；
- 不用大量原文代替综合；
- 对随时间变化的信息标注核对日期。
