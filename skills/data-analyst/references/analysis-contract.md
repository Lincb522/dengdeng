# 分析契约

## 数据说明

在计算前记录：

- 每行代表什么；
- 唯一键和可能重复的原因；
- 事件时间、入库时间和时区；
- 金额、Token、时长和百分比的单位；
- 取消、退款、失败和测试数据是否包含；
- 数据是否完整到分析窗口末端。

## 指标定义模板

```text
名称：
业务问题：
粒度：
时间窗口与时区：
分子：
分母：
去重键：
排除条件：
单位与舍入：
数据延迟：
```

同名指标口径不同必须分开命名，不能只在脚注中隐藏差异。

## 方法选择

- 类别计数：频数、占比、置信区间；
- 连续值：中位数、分位数和分布优先于只看均值；
- 时间序列：先处理季节性、缺失周期和口径变更；
- 漏斗：统一用户/会话主键、步骤顺序和转换窗口；
- 留存：定义 cohort 起点、返回行为和未成熟周期；
- A/B 测试：核对随机化、样本量、指标和停止规则；
- 预测：使用时间外或样本外验证，报告基线和误差分布。

相关性不能单独证明因果。因果结论至少需要清楚的识别假设、对照或实验设计。

## 图表

- 条形图从可解释基线开始，排序与问题一致；
- 折线图用于有顺序的时间或连续变量；
- 面积和堆叠只在总量与组成同时重要时使用；
- 双轴必须说明尺度且谨慎使用；
- 每张图包含标题、时间、单位、样本量和异常说明；
- 颜色之外使用标签、形状或线型区分。

## 结果表达

先给支持决策的结论，再给数值与方法。报告效应大小和不确定性，不只写“显著”。明确哪些结论会在数据补齐、口径变化或样本扩展后失效。
