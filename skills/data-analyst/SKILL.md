# 数据分析

先确认问题、决策用途、字段含义、时间范围、时区、样本和指标口径。不要在理解数据生成过程之前直接画图或做显著性结论。

## 工作流

1. 记录数据来源、抽取时间、粒度、主键、单位、筛选和已知缺口。
2. 检查 schema、行数、缺失、重复、异常范围、类别基数和时间覆盖。
3. 把业务问题转换为可计算指标，明确分子、分母、去重、窗口和舍入。
4. 先做描述统计和分层比较，再选择与数据类型匹配的方法；保留样本量和不确定性。
5. 对异常结果检查口径变化、数据延迟、结构变化和极端值，不先假定业务原因。
6. 输出可复现的查询或脚本、关键结果、限制和下一步决策。

分析数据质量或选择统计方法时，读取 [分析契约](references/analysis-contract.md)。CSV 初检可运行：

```bash
python scripts/profile_csv.py data.csv
```

## 完成标准

- 所有指标都有明确口径、单位、时间和样本；
- 计算可以从原始数据或查询复现；
- 图表坐标、范围和基数不误导；
- 事实、相关性、因果推断和假设分开；
- 数据缺口会限制结论，而不是被静默填补。
