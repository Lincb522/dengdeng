# HTTP 契约指南

## 资源与方法

- `GET` 读取且无业务副作用；
- `POST` 创建或执行不可自然幂等的动作，配合幂等键；
- `PUT` 替换或写入已知资源，重复请求结果一致；
- `PATCH` 修改明确字段，区分未提供与显式清空；
- `DELETE` 重复调用应得到稳定、可解释的结果。

路径使用稳定资源名，动作端点只用于无法自然表达为资源状态的操作。

## 状态码

| 状态 | 含义 |
| --- | --- |
| 200 | 成功读取或同步操作完成 |
| 201 | 资源已创建，并返回资源或 Location |
| 202 | 已接受异步处理，返回可查询状态 |
| 204 | 成功且没有响应体 |
| 400 | 请求语法或字段无效 |
| 401 | 缺少或无效身份 |
| 403 | 身份有效但无权限 |
| 404 | 资源不存在或按隐私策略不可见 |
| 409 | 当前资源状态冲突或幂等内容冲突 |
| 422 | 语法有效但不满足业务规则 |
| 429 | 限流，提供可用的重试时间 |
| 502/503/504 | 上游无效、当前不可用或超时，责任边界需清楚 |

错误体至少包含稳定 `error_code`、直接 `message` 和请求关联 ID。客户端逻辑依赖错误码，不依赖英文字符串。

## 列表与分页

- 排序字段与方向必须真实生效并稳定；
- 相同排序值使用唯一 ID 作为第二排序键；
- 游标绑定筛选和排序条件，不能跨条件复用；
- 返回空数组而不是 `null`；
- 总数计算昂贵时明确是否省略或近似。

## 幂等

幂等记录绑定用户、操作、请求摘要和有效期。相同键相同内容返回原结果；相同键不同内容返回冲突。不要在外部副作用完成后才写幂等状态。

## SSE 与 WebSocket

- 记录事件类型、序号、心跳、结束和错误事件；
- 定义断线重连、重复事件和客户端取消；
- 流开始后不能再依赖 HTTP 状态码表达业务错误；
- 网关和反向代理禁用不适当缓冲并设置匹配的空闲超时。

## 兼容性

通常可兼容：新增可选字段、增加新端点、扩展客户端允许忽略的响应字段。

通常破坏兼容：改变字段类型或单位、收紧必填、重命名、改变默认排序、删除枚举值、改变错误码或认证方式。破坏性变化需要新版本或明确迁移期。
