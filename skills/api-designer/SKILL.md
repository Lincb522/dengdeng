# API 设计

从真实客户端任务和现有协议开始，不把数据库表直接暴露成 API，也不为理论扩展增加未使用字段。

## 工作流

1. 列出调用者、身份、资源所有权、操作目标和当前契约。
2. 定义方法、路径、请求头、路径参数、查询参数、请求体和内容类型。
3. 定义成功响应、空结果、异步状态、流式事件、错误和重试语义。
4. 对创建、支付、扣费和任务操作定义幂等；对列表定义稳定排序、游标或页码边界。
5. 检查旧客户端、未知字段、默认值、枚举扩展和版本升级。
6. 提供可直接执行的最小请求、响应示例和负面用例。

设计详细 HTTP 行为时，读取 [HTTP 契约指南](references/http-contracts.md)。

## 交付内容

- 资源与操作；
- 权限矩阵；
- 完整请求和响应 schema；
- 状态码与稳定错误码；
- 幂等、分页、限流和缓存；
- 兼容性与迁移；
- 正向、边界和失败示例。
