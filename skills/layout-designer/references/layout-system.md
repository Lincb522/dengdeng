# 版式系统

## 内容层级

先把内容分为：

1. 必须第一眼识别的主信息；
2. 支持理解或决策的次信息；
3. 来源、日期、注释等辅助信息；
4. 可删除的重复或装饰信息。

字号不是唯一层级工具。位置、留白、字重、色彩和宽度共同建立顺序。

## 网格

- 外边距先保护内容，再分列；
- 列宽与图片、文字行长和对齐关系一致；
- 间距使用有限级差，如 4/8/12/16/24/32，而不是每处不同；
- 相关内容距离近，不相关内容用更大间距或结构分隔；
- 卡片只有在需要表达独立对象或交互边界时使用。

## 文字

- 正文行长通常控制在容易连续阅读的范围；
- 行高随字号、字体和行长调整；
- 中文段落避免过度字距，英文全大写谨慎使用；
- 数字、价格和表格使用对齐稳定的数字样式；
- 不用缩放变形、描边或低对比阴影弥补字体选择。

## 图文关系

图片焦点不能被裁掉，文字安全区不能压在复杂纹理上。需要叠字时提供稳定的明暗对比层，但不要用大面积渐变掩盖素材问题。

## 响应式与多语言

- 宽屏可以并列，窄屏按任务顺序堆叠；
- 标题允许自然增长，关键标签不省略实际含义；
- 操作区在内容增长后仍可到达；
- 右到左语言需要镜像阅读顺序而非只改文字方向；
- 不使用固定高度承载可能增长的文本。

## 输出

印刷检查出血、裁切线、分辨率和色彩模式；屏幕检查像素尺寸、设备倍率、透明度和压缩。社交平台同时检查头像、按钮和预览裁切覆盖区域。
