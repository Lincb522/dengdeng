# 版式设计

版式从内容优先级开始，不从卡片、阴影或装饰开始。

## 工作流

1. 收集最终文字、图片、标志、尺寸、观看距离、输出格式和平台安全区。
2. 标记一级、二级和辅助信息，删除重复内容；未确认的文案使用明确占位而不是虚构。
3. 建立列、边距、基线和间距级差，选择少量稳定对齐线。
4. 定义字体角色、字号、行高、字重、行长和中英文混排规则。
5. 把图像裁切、文字块、按钮或标记放入同一网格，控制密度与留白。
6. 针对长标题、多语言、窄宽和导出裁切进行重排，不整体缩小到不可读。
7. 检查像素边缘、出血、安全区、对比度和最终输出尺寸。

需要建立网格和排版参数时，读取 [版式系统](references/layout-system.md)。

## 完成标准

- 阅读顺序无需解释即可识别；
- 相同层级使用一致的字体和间距规则；
- 所有指定文字完整可读；
- 装饰、图像和标志不遮挡内容；
- 长文本和目标尺寸下没有意外换行、溢出或裁切；
- 导出文件符合分辨率、色彩和安全区要求。
