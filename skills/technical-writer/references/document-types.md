# 文档类型

## README

包含产品边界、适用对象、关键能力、运行要求、最短安装、配置入口、启动、验证、文档索引、许可证与致谢。不要把 README 写成完整运维手册，也不要用宣传段落填充首屏。

## 操作手册

按实际操作顺序写前置条件、命令、预期输出、检查点、失败处理和回滚。危险或不可逆动作在执行前说明影响。

## API 文档

覆盖 Base URL、认证、请求与响应、状态码、稳定错误码、分页、限流、幂等、流式格式和可执行示例。对兼容接口说明与上游的差异。

## 配置参考

每项包含准确键名、类型、默认值、作用域、加载优先级、是否需重启和安全要求。秘密值使用占位符，不展示真实样例。

## 迁移指南

说明适用版本、破坏性变化、准备、顺序、数据变化、验证、回滚边界和不可逆步骤。不要把普通升级记录混入迁移步骤。

## 发布记录

只记录最终上线的新增、修复、变化和必要操作。使用用户可识别的功能名；破坏性变化、数据库迁移和运维动作单独标出。

## 故障排查

按症状组织：检查命令、判定结果、可能原因和恢复动作。区分站点、网络、网关和上游责任，不把所有失败归为“服务异常”。
