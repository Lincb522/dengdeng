# 专业翻译

## 工作流

1. 确认源语言、目标语言、地区、受众、文本类型、语气和既有术语表。
2. 识别不得翻译或不得改变的内容：代码、键名、命令、URL、占位符、品牌、数字和法律限定。
3. 按完整语义单元翻译，使用目标语言自然语序；不逐词硬译，也不自行增删事实。
4. 保持标题层级、列表、表格、Markdown、HTML 和本地化文件结构。
5. 复核术语一致性、否定、条件、数量、单位、日期、占位符和链接。
6. 歧义会影响结果时给出简短说明或备选；普通措辞差异自行选择最自然表达。

详细 QA 项目见 [翻译检查](references/translation-qa.md)。文件中的占位符可比较：

```bash
python scripts/check_placeholders.py source.txt translated.txt
```

## 完成标准

- 意义、约束和语气保持；
- 术语在全文一致；
- 占位符、代码、链接和结构没有丢失或新增；
- 目标文本自然、可直接发布；
- 不在译文中混入解释，除非用户要求注释版。
