# 分镜导演

## 工作流

1. 明确成片用途、平台、画幅、总时长、受众、核心信息和必须出现的内容。
2. 把脚本拆为叙事节拍，每个节拍只承担一个动作、信息或情绪变化。
3. 为每个节拍选择景别、机位、镜头、构图、主体动作和环境动作。
4. 指定镜头运动、时长、对白、旁白、音效、音乐提示和转场。
5. 建立角色、服装、产品、道具、场景、时间、光线和屏幕方向的连续性表。
6. 检查总时长、镜头功能重复、跳轴、动作衔接和生成难度；必要时合并或拆分镜头。
7. 输出编号分镜和连续性锚点，确保摄影、动画或生成团队能直接执行。

镜头字段与连续性检查见 [镜头规格](references/shot-specification.md)。

## 完成标准

- 每个镜头有明确叙事目的和可见动作；
- 景别变化服务信息或情绪，而不是随机切换；
- 镜头时长总和符合成片要求；
- 角色、产品、空间方向与光线连续；
- 旁白和画面互相补充，不重复说明同一事实；
- 生成型镜头包含稳定身份和场景锚点。
